# html-maker

영업 발표 자료를 PPT 대신 HTML로 만드는 도구입니다.

어떤 발표인지(종류, 듣는 사람, 시간, 발표 방식)를 고르면 그 발표에 맞는 장 구성과 레이아웃을 잡아 줍니다. 사람은 칸마다 적힌 안내를 보고 내용만 채우면 됩니다.

## 이렇게 씁니다

1. **새 발표 만들기**에서 발표 종류를 고릅니다. (신규 고객 제안, 제품 소개, 성과 리뷰, 회사 소개)
2. 듣는 사람과 발표 시간을 고르면 몇 장으로 구성되는지 바로 보여 줍니다.
3. 제목, 고객사, 발표자를 적고 테마를 고르면 편집 화면이 열립니다.
4. 슬라이드 위 글자를 눌러 바로 고칩니다. 오른쪽에는 이 장에서 무엇을 말해야 하는지, 아직 비어 있는 칸이 어디인지 나옵니다.
5. **발표하기**(F5)로 전체 화면 발표를 하거나, **내보내기**로 파일을 만듭니다.
   - **발표 파일 (HTML)**: 파일 하나로 열리고, 인터넷이 없어도 글꼴까지 그대로 보입니다. 고객에게 메일로 보내도 됩니다. 발표자 노트는 들어가지 않습니다.
   - **PDF**: 인쇄 창에서 "PDF로 저장"을 고르면 됩니다.

처음이라면 홈의 **완성된 예시 보기**로 다 채운 발표가 어떻게 보이는지 먼저 확인해 보세요.

## 보안

- 입력한 내용은 이 브라우저(IndexedDB)에만 저장됩니다. 서버로 보내지 않고, AI에도 보내지 않습니다.
- 다른 컴퓨터로 옮기거나 백업하려면 HTML로 내보낸 뒤, 홈의 **파일 열기**로 다시 불러오면 됩니다.
- 브라우저 데이터를 지우면 저장된 발표도 지워집니다. 중요한 발표는 HTML로 내보내 두세요.

## 개발

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 구성 생성 규칙 테스트
npm run build      # dist/ 에 정적 파일 생성
```

`dist/`는 정적 파일만 있어서 사내 웹 서버나 공유 폴더 어디에 올려도 동작합니다.

설계와 앞으로 할 일은 [docs/DESIGN.md](docs/DESIGN.md)에 있습니다.
