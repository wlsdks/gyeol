# html-maker

영업 발표 자료를 PPT 대신 HTML로 만드는 도구입니다.

어떤 발표인지(종류, 듣는 사람, 시간, 발표 방식)를 고르면 그 발표에 맞는 장 구성과 레이아웃을 잡아 줍니다. 사람은 칸마다 적힌 안내를 보고 내용만 채우면 됩니다.

## 이렇게 씁니다

1. **새 발표 만들기**에서 발표 종류를 고릅니다. (신규 고객 제안, 제품 소개, 성과 리뷰, 회사 소개)
2. 듣는 사람과 발표 시간을 고르면 몇 장으로 구성되는지 바로 보여 줍니다.
3. 제목, 고객사, 발표자를 적고 테마를 고르면 편집 화면이 열립니다.
4. 슬라이드 위 글자를 눌러 바로 고칩니다. 오른쪽에는 이 장에서 무엇을 말해야 하는지, 아직 비어 있는 칸이 어디인지 나옵니다.
5. **발표하기**(F5)로 전체 화면 발표를 하거나, **내보내기**로 파일을 만듭니다.
   - **발표 파일 (HTML)**: 파일 하나로 열리고, 인터넷이 없어도 글꼴까지 그대로 보입니다. 고객에게 메일로 보내도 됩니다. 발표자 노트는 들어가지 않습니다.
   - **PDF**: 인쇄 창에서 "PDF로 저장"을 고르면 됩니다.

처음이라면 홈의 **완성된 예시 보기**로 다 채운 발표가 어떻게 보이는지 먼저 확인해 보세요.

## 저장과 버전

처음 한 번 홈에서 **보관 폴더 고르기**를 눌러 PC 폴더(예: `문서/발표자료`)나 팀 공유 드라이브 폴더를 정해 두세요. 그 뒤로는 고칠 때마다 저장 버튼 없이 자동으로 저장됩니다.

```
발표자료/
├─ 한빛제조 품질 관리 제안.deck        ← 작업 파일 (발표자 노트 포함)
├─ 버전 기록/
│  └─ 한빛제조 품질 관리 제안/
│     ├─ 2026-10-23 15-12 고객 전달본.deck
│     └─ 2026-10-23 16-40 자동.deck
└─ 지운 발표/                          ← 지운 발표는 여기로 옮겨 둡니다
```

- **두 곳에 저장:** 브라우저 안(IndexedDB)과 보관 폴더에 같이 저장합니다. 브라우저 기록을 지워도 폴더의 파일은 남고, 다른 PC에서 같은 폴더를 고르면 발표가 그대로 들어옵니다. 두 곳 내용이 다르면 더 최근에 고친 쪽을 열고, 덮이는 쪽은 버전으로 남깁니다.
- **버전 기록:** 편집 화면 위쪽의 시계 버튼을 누르면 열립니다.
  - **지금 상태를 버전으로 남기기**로 "고객 전달본"처럼 이름을 붙이면 지우기 전까지 보관됩니다.
  - 자동 저장 버전은 열 때, 고치는 중 10분마다, 발표하거나 내보내기 전, 되돌리기 전에 남습니다. 발표마다 최근 30개(폴더에는 10개)를 둡니다.
  - 버전을 누르면 그때 모습을 장마다 보여 주고, 지금과 다른 장을 표시합니다. 되돌리면 되돌리기 전 상태도 버전으로 남으니 언제든 다시 돌아올 수 있습니다.
- **크롬, 엣지에서 폴더 저장이 됩니다.** 브라우저를 새로 열면 폴더 사용을 한 번 더 허용해야 합니다(홈과 편집 화면에 **허용하기**가 나옵니다). 다른 브라우저에서는 **내보내기 → 작업 파일 (.deck)**로 내려받아 두고, **파일 열기**로 다시 불러옵니다.
- 작업 파일(.deck)과 발표 파일(.html)은 다릅니다. 작업 파일에는 발표자 노트가 들어 있으니 고객에게는 발표 파일을 보내세요.

## 보안

- 입력한 내용은 이 브라우저와 사용자가 고른 폴더에만 저장됩니다. 서버로 보내지 않고, AI에도 보내지 않습니다.

## 개발

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 구성 생성 규칙, 작업 파일, 버전 비교 테스트
npm run build      # dist/ 에 정적 파일 생성
```

`dist/`는 정적 파일만 있어서 사내 웹 서버나 공유 폴더 어디에 올려도 동작합니다.

설계와 앞으로 할 일은 [docs/DESIGN.md](docs/DESIGN.md)에 있습니다.
